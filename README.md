## Descrition

Spots is a photo-sharing web app where users can add, edit, and delete cards showing their favorite places. It connects to a real API to save user profiles, avatars, and posts, so data stays synced even after refreshing. Built with JavaScript, HTML, and CSS, the project focuses on modular code using classes, responsive design, and smooth user interactions through popups and form validation.
